## 🌟 Featured Projects

### [InsureFlow AI](https://github.com/parimalgavali/insureflow-ai)

A full-stack insurance claims and policy intelligence platform inspired by real P&C insurance workflows. It combines Spring Boot services, Python AI APIs, local ML training, document intelligence, RAG, a Vue adjuster workbench, governance controls, observability, and cloud-ready deployment.

**Highlights:** AI-assisted triage · Document extraction · Grounded RAG assistant · Human review · Audit trails · Model cards · CI and security scanning

**Technology:** Java 21 · Spring Boot · Python · FastAPI · Scikit-learn · Vue 3 · PostgreSQL · Docker · Azure · Prometheus · Grafana

### [Early Sepsis Prediction](https://github.com/parimalgavali/cdss_project)

A clinical decision-support research project that investigates how predictive performance changes across early-warning horizons. It compares classical machine-learning baselines with LSTM and GRU models and evaluates how early sequential models can detect sepsis.

**Technology:** Python · PyTorch · Scikit-learn · Pandas · Time-series ML · Clinical data analysis
